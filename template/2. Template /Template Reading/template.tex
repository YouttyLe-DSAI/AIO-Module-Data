\section{Tiêu đề, đoạn văn và định dạng chữ}

Một số định dạng hay dùng:
\begin{itemize}
    \item \textbf{In đậm}: dùng cho keyword hoặc ý quan trọng.
    \item \textit{In nghiêng}: dùng cho thuật ngữ hoặc nhấn nhẹ.
    \item \texttt{Code inline}: dùng cho tên hàm, biến, file, ví dụ \texttt{train.py}.
\end{itemize}

\subsection{Danh sách đánh số}

\begin{enumerate}
    \item Bước 1: tạo hoặc copy file \texttt{.tex}.
    \item Bước 2: viết nội dung sau \texttt{\textbackslash begin\{document\}}.
    \item Bước 3: recompile để xem PDF.
\end{enumerate}

\section{Code box}

\subsection{aivncodebox: dùng cho code đề bài hoặc code minh họa}

\begin{aivncodebox}[Ví dụ code Python]
\begin{python}
def sigmoid(x):
    return 1 / (1 + math.exp(-x))

print(sigmoid(0))
\end{python}
\end{aivncodebox}

\subsection{aivnCodeOutput: dùng cho output hoặc lời giải code}

\begin{aivnCodeOutput}[Output minh họa]
\begin{python}
0.5
\end{python}
\end{aivnCodeOutput}

\section{Các box ghi chú và giải thích}

\subsection{guidelinebox}

\begin{guidelinebox}{Lời giải}
Box này dùng để viết hướng dẫn, mẹo làm bài, hoặc phần giải thích ngắn trong file lời giải. Ví dụ: nhắc người học kiểm tra kiểu dữ liệu trước khi tính toán.
\end{guidelinebox}

\subsection{notebox}

\begin{notebox}
Box này dùng cho lưu ý quan trọng. Ví dụ: ``Không chỉnh phần preamble nếu không thật sự cần thiết.''
\end{notebox}

\subsection{infobox}

\begin{infobox}{Thông tin chính cần nắm}
Python là một ngôn ngữ lập trình cấp cao, thông dịch, đa mục đích và có cú pháp rõ ràng, dễ học. Nó hỗ trợ nhiều mô hình lập trình như hướng thủ tục, hướng đối tượng và hàm. Python được sử dụng rộng rãi trong khoa học dữ liệu, trí tuệ nhân tạo, phát triển web, tự động hóa và nhiều lĩnh vực khác.
\end{infobox}

\subsection{examplebox}

\begin{examplebox}{Ví dụ minh họa}
Giả sử cần giải thích \textbf{missing value}, ta có thể đưa một bảng nhỏ và hỏi người học: dòng nào đang thiếu dữ liệu?
\end{examplebox}
